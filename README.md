# Social Network

NestJS backend for a social network. Includes authentication, users, posts, follows, a realtime feed, moderation tools, and payment handling.

- Location: `social-network/` — a TypeScript NestJS app.
- Key modules: `auth`, `users`, `posts`, `follows`, `feed`, `moderation`, `payments`.

### Quick start

```bash
npm install
npm run start:dev
```
